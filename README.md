# VÉNDO — Infraestructura Web de Alta Conversión

Plataforma de comercio electrónico y venta ágil de servicios y soluciones web para emprendimientos, empresas y marcas que buscan aumentar su alcance y facturación.

Desarrollado bajo las especificaciones de la **Skill: Véndo E-commerce UI/UX Architect**:
- **Mobile-First & App-Like**: Pensado para pantallas de 390px a 430px con sensación táctil fluida.
- **Paleta Minimalista & Alto Contraste**: Canvas limpio (`#FFFFFF` / `#FAFAFA`), contraste fuerte (`#111111`) y acentos de conversión (`#2563EB`, `#10B981`).
- **Arquitectura CRO**:
  - Catálogo interactivo de soluciones digitales tratadas como productos transaccionales.
  - Sticky Bottom Bar para móviles con acceso permanente al catálogo y WhatsApp.
  - Bottom Sheet modal deslizante para selección de addons y checkout exprés en 1 clic.
  - Bento Grid de beneficios con métricas de rendimiento reales (<0.8s de carga).
  - Proceso de 3 pasos y preguntas frecuentes orientadas a eliminar objeciones.
